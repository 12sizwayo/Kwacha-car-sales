## Question 2: HTML Elements

### 1. Five HTML Elements I Found Most Challenging
1. `<img>` – Managing image paths and ensuring images display correctly.
2. `<section>` – Structuring related content without CSS.
3. `<article>` – Separating individual car listings properly.
4. `<nav>` – Organizing navigation links clearly.
5. `<form>` – Structuring inputs correctly without JavaScript.

### 2. Use of Semantic HTML Elements
Semantic elements such as `<header>`, `<nav>`, `<section>`, `<article>`, and `<footer>` were used to give meaning to the structure of the website.  
They improve readability, accessibility, and organization of the content.

### 3. Most Useful Element for Organizing Layout
The `<section>` element was the most useful because it allowed me to group related content, such as car listings and contact information, in a structured way.

## Question 3: HTML Attributes

### 1. Three Essential Attributes
- `src` – Used to load images.
- `href` – Used for navigation links.
- `alt` – Improves accessibility for images.

### 2. Use of `class` and `id`
- `id` was used for unique sections like navigation targets.
- `class` was used for grouping similar elements such as car listings.

### 3. Attribute That Improved User Experience the Most
The `alt` attribute improved accessibility by providing descriptive text when images cannot be displayed.
